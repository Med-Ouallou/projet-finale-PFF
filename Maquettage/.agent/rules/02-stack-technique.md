# Stack Technique (Static Only)

## 1. Front-End (Structure & Style)
*   **HTML** : HTML5 sémantique obligatoire.
*   **CSS** : Tailwind CSS v3 via CDN (pour le prototypage rapide) ou fichiers CSS locaux si validé.
*   **JS** : Vanilla JS.
*   **Frameworks** : React/Vue/Alpine INTERDITS sauf demande explicite.

Rules For Css:
- Use ONLY Preline UI components.
- Do NOT create custom Tailwind buttons.
- Use official Preline component structure.
- Use hs- classes when required.
- Include necessary data-hs attributes.
- No raw Tailwind-only components.

If a component does not exist in Preline, do not invent one.
