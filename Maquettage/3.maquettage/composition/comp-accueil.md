## Structure de Composition

### 1. Atoms (Preline Components)
- `base/button` : Bouton standard Preline (Solid/Outline).
- `base/title` : h1, h2 avec classes Tailwind.
- `base/text` : Paragraphes.
- `base/logo` : Logo SVG RestoManager.

### 2. Molecules (Preline Assemblies)
- `navigation/navbar` : Header standard Preline avec Collapse.
- `hero/hero-section` : Hero avec grille 2 colonnes (Texte + Image/Visual).
- `content/feature-card` : Carte avec icône Preline.
- `layout/features-grid` : Grille de caractéristiques.
- `navigation/footer` : Footer multi-colonnes Preline.
